Le stock de chaque boutique, en une question.

HBntory gère l'inventaire d'une enseigne à plusieurs succursales. Les équipes pilotent le stock dans un backoffice sécurisé, et n'importe quel client peut demander en langage naturel si un produit est disponible.

Le projet

Deux mondes, une seule base de données

Le backoffice et l'interface publique ne se parlent jamais directement. Ils partagent seulement la base SQLite. Les fiches produits (nom, prix, description) ne sont jamais copiées en local : elles viennent toujours de la Product API fournie par l'école.

Interne · authentifié

Backoffice

Application Flask pour les équipes de l'enseigne.

  • Employés : entrées et sorties de stock de leur succursale
  • Admins : gestion des comptes et des rôles
  • Sessions Flask-Login, mots de passe hachés avec bcrypt
Public · sans compte

Interface client

Une page ouverte à tous, avec un assistant IA.

  • Questions en langage naturel sur les produits et le stock
  • Agent IA (Groq) relié à un serveur MCP
  • Mode clair et mode sombre

Assistant IA

Le trajet d'une question

Chaque question est indépendante : une simple requête REST, sans historique à conserver.

1

Client web

client_web/

Le visiteur tape sa question dans le chat.

2

AI Service

ai_service/

L'agent choisit les outils à appeler via le LLM Groq.

3

Serveur MCP

product_mcp_server/

Il lit le stock en base et les fiches de la Product API.

4

Réponse

JSON → chat

L'agent rédige une réponse claire, succursale par succursale.
